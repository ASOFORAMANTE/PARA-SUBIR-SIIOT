# PARA-SUBIR-SIIOT

Videos aprobados de **@siiot_cl** listos para publicar. Este repo es público a propósito: Instagram necesita descargar cada video desde una URL pública.

- `videos/NNN-tema.mp4`: el video (vertical 1080×1920).
- `videos/NNN-tema.jpg`: la portada.
- `videos/NNN-tema.txt`: la descripción con hashtags.
- `calendario.json`: qué se publica, cuándo (hora de Chile) y qué ya se publicó, con el link del post.

URL pública de cada video (GitHub Pages):
`https://asoforamante.github.io/PARA-SUBIR-SIIOT/videos/NNN-tema.mp4`

Los videos se producen en el repo privado `siiot-conenitdo`. Solo llegan aquí cuando Renato los aprueba, y solo se publican con su "sí".
