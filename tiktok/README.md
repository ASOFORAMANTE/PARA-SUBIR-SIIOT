# TikTok @siiot_: primera tanda (25 videos)

Cómo subirlos (unos 15 min por tanda):
1. En el computador abre **tiktok.com/tiktokstudio** → Subir.
2. Descarga el video con el link "video" (clic derecho → Guardar como, o en el celular: compartir → Guardar en Archivos).
3. Abre el link "texto", copia todo y pégalo como descripción.
4. Programa con la fecha y hora de la tabla (TikTok deja programar hasta 10 días antes).

Horario: 4 por día a horas distintas (09:00, 13:00, 18:30 y 21:30, hora de Chile) para ver cuál funciona mejor. Los temas parecidos (SEO, IA, versiones héroe) quedan separados.
